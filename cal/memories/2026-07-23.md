# 2026-07-23

## Meeting: Edit Swerve

**Date:** 2026-07-23
**Participants:** Cal (facilitator), Architect, Product Strategist, Risk (ad-hoc expert agents)

### Key Insights
- Editing *completes* the relay rather than diluting it — a relay where the
  human can only flip AI-installed switches is half a conversation. The
  "just pipes" soul survives: native text editing is another pipe.
- The whole stale-range corruption class existed *because* there is no
  in-memory document model. The editor migration's Phase 0 (introduce
  `MarkdownDocument`, invert click→patch→disk to keystroke→model→disk)
  fixes the architecture that caused the July sweep's worst bugs.
- Plain mode (NSTextView) ships editing first — undo/IME/Writing Tools for
  free. Enhanced gets per-block inline editing (Phase 3) on the stable block
  ids shipped in 47e59ce. Full WYSIWYG deferred to post-data Phase 4.
- Round-trip fidelity elevated to sacred: edit one word → diff of exactly
  that word. AI agents diff these files; noisy writes poison the relay.
- Editing is free; Relay Pro keeps the collaboration layer + gains
  CriticMarkup authoring. "Editing is free. Collaborating with your AI is Pro."
- "Editor" ASO terms have ~10× the volume of "reader" terms — the largest
  marketing win of the migration.

### Decisions Made
- **Pixley becomes an editor** — Rationale: app is too big not to allow
  direct editing; users can change documents twenty structured ways but
  can't fix a typo. Confidence: decided (Jose, final). Revisit-if: never.
- **BRD as meeting output, Lisa to spec the migration** — Rationale: the
  hard remaining questions (save model, conflict UX, structure protection)
  are spec-interview material. Confidence: high.
- **Plain-first, phased, each phase shippable** — Rationale: NSTextView
  free-rides system text behavior; solo capacity demands reader stays
  releasable throughout. Confidence: high. Revisit-if: text-surface spike
  invalidates NSTextView path.
- **Editing free / Pro = collaboration + CriticMarkup authoring** —
  Rationale: charging for commodity editing while giving away the
  differentiator would be backwards. Confidence: medium-high. Revisit-if:
  conversion data post-launch.
